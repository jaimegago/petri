# Decisions

Architectural decision records (ADRs) live in [`docs/decisions/`](docs/decisions/).
Each non-obvious choice is one file named `NNNN-slug.md`. See
[`docs/decisions/README.md`](docs/decisions/README.md) for the convention and
when to add a new ADR.

This top-level pointer exists so contributors browsing the repo root find the
log on the first try.
